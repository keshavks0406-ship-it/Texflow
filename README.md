# TexFlow

Mobile-first textile factory management app. Stage 1 establishes the installable PWA shell and demo dashboard.

## Stage 1 scope
- React + TypeScript + Vite
- Installable Progressive Web App (PWA)
- Mobile-first responsive dashboard
- English / Tamil language switch
- Factory selection
- Demo entry (no real authentication)
- Sample production, job-order, dispatch and collection figures

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

## Important
This is a frontend-only demo. The dashboard figures are sample data; login, database, permissions, and real factory transactions are not connected yet. Those will be planned and implemented in later stages.

## Technology
- React 18
- TypeScript
- Vite
- vite-plugin-pwa
- Lucide icons
